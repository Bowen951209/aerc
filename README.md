# [aerc](https://aerc-mail.org/) patched for Mail2000.

Mail2000 is known to have quirky IMAP implementation. This branch is
basically aerc but patched `go-imap` for Mail2000. Learn more here:
<https://github.com/Bowen951209/go-imap-mail2000>

# Build & Install

Please build and install from source. You can follow the guide here:
<https://git.sr.ht/~rjarry/aerc/tree/master/item/README.md#from-source>
